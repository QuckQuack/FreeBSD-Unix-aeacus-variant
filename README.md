# FreeBSD Port of Aeacus

Due to let’s say current events, I have decided to create a version of Aeacus for FreeBSD/Unix.

I do not claim, nor intend to imply, that I created the Aeacus project, I was not involved in its creation in any way.

Once this BSD version has been tested and troubleshooted, I intend to open a pull request on the official Aeacus GitHub. If that pull request is approved, I will take this repository down.

The BSD version must be compiled yourself; please refer to `compiling.md` for instructions.

Refer to the main aeacus repository for any questions, or contact me on Discord: `@brody001301` (aka gooseman) on the Cyber server.
